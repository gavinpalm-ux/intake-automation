# Rollout Plan

How I would take this from a working prototype to something a real team uses every day.

## Phase 1: Discovery (week 1–2)

- Shadow the person who handles intake today and time 20–30 real inquiries to set an honest baseline.
- Pull 100+ past inquiries and label the correct answers with the team. This becomes the test set.
- Agree on success metrics with the sales manager: time per inquiry, speed to first reply on urgent requests, and field accuracy.
- Review scoring weights and routing rules together so they match how the team actually sells.

## Phase 2: Pilot in shadow mode (week 3–4)

- Run the system alongside the manual process. Staff work as usual; the system's results are compared to theirs.
- Track where they disagree and tune rules, prompts and weights.
- **Go/no-go gate:** 90%+ field accuracy on the labeled set, and the team agrees the priority order makes sense.

## Phase 3: Assisted go-live (week 5–8)

- Reps start working from the prioritized queue and drafts. Every reply is still reviewed before sending.
- Weekly 15-minute check-in: what did it get wrong, what's annoying, what should change.
- Short how-to guide and a 30-minute training session. A named point of contact for questions.

## Phase 4: Scale and integrate (month 3+)

- Connect directly to the shared inbox and CRM so nobody touches CSV files.
- Consider auto-sending replies only for the simplest, low-risk category, and only if the data supports it.
- Revisit scoring weights using real conversion data (which leads actually became customers).

## Change management

| Concern people raise | How it's addressed |
|---|---|
| "Is this replacing my job?" | It removes retyping and sorting, not judgment. Reps spend the saved time on calls and follow-ups. |
| "What if it gets something wrong?" | Every message is reviewed before it goes out, and the system flags what it's unsure about. |
| "I don't trust AI with customer data." | The offline engine keeps all data local; the AI engine is opt-in and can be turned off. |

## Success metrics after 60 days

- Intake time per inquiry down 50%+
- Urgent requests answered within 2 business hours
- Field accuracy holding at 90%+ on spot checks
- Team adoption: reps using the queue daily without being reminded
